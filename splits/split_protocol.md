# Split protocol

Three deployment-aligned evaluation views are used:

1. **Chronological in-domain evaluation** — future periods from a known domain.
2. **Grouped building-held-out evaluation** — building identities are excluded while broader site context remains available.
3. **Exact site-held-out evaluation** — a complete site is withheld from fitting and source calibration.

Randomly mixed overlapping windows are not used as the primary deployment evidence.

The exact site-held-out cohort contains 476 building-series across nine sites. Crow has three eligible series but is not treated as an independent site holdout.
