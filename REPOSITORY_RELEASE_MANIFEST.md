# HVAC-XForecast public repository release manifest

## Included
- site-level cohort manifest
- site-held-out membership definition
- split protocol
- forecast-task configuration
- reliability evaluation configuration
- stress-test configuration
- delayed recalibration configuration
- empirical risk-budget configuration
- selected machine-readable result tables
- analysis and reproducibility scope documentation

## Excluded
- raw BDG2 observations
- third-party pretrained model weights
- credentials or API keys
- unverified software-version claims

## Release boundary
The current public package supports verification of cohort definitions, protocol settings, selected result tables, and empirical risk-budget endpoints. It is not represented as a complete end-to-end retraining package.
