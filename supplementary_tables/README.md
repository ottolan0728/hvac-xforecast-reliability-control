# Machine-readable result tables

This directory contains selected machine-readable tables underlying the manuscript and Supplementary Material.

Included:
- site-held point metrics
- site-held interval reliability
- representative PatchTST delayed recalibration
- primary nine-site empirical risk-budget retention

Compact metric names:
- Cov90: empirical 90% interval coverage
- CovErr90: mean building-level absolute deviation from nominal 90% coverage
- PeakCov90: peak-conditional 90% interval coverage

The paper and Supplementary Material contain additional expanded tables. Raw BDG2 observations are not redistributed.
