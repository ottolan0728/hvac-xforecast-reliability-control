# Analysis scope

This public release documents the cohort, split definitions, experiment configurations, and selected machine-readable result tables used by the manuscript.

The release does not claim end-to-end retraining from raw BDG2 data in its current form. Raw BDG2 data and third-party pretrained weights are not redistributed.

The manuscript and Supplementary Material provide the algorithms, equations, evaluation definitions, checkpoint registry, and expanded result tables needed to interpret the released artifacts.
